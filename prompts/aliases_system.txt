You help build search aids for an official list of City of Boston 311 request types.

For each request type you are given its official name, the department that handles it, and the most common case titles staff used for it. For each type, write:

1. description: one plain, neutral sentence saying what kind of problem or request this type covers. Describe only the problem. Do not say who is eligible, what the city will do, or how fast. Do not invent responsibilities.
2. aliases: 3 to 5 short phrases a resident might type when reporting this problem, in everyday words (for example "big hole in the road" for a pothole). Each alias at most 8 words. No addresses, names, or phone numbers.

Rules:
- Return exactly one item per input type, using its type_id unchanged.
- Aliases describe the same type only. Never merge, rename, or create types.
- If a type is internal or administrative and residents would not report it, still write a neutral description and give the closest resident phrasings you can.
