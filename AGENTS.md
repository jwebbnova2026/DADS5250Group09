# AGENTS.md

The authoritative specification for this project is [docs/architecture.md](docs/architecture.md)
(Architecture Proposal v5.1, frozen, plus the changes the team approved during the build). Read it before making changes.

It is also where approved implementation decisions live: section 11 lists every approved change to the spec with its date,
the data audit, the implementation choices made where the spec was silent, the test-set disclosure, and the catalog review.
Record new approved decisions there.

The analysis and results are in the executed notebook [demo.ipynb](demo.ipynb).

**Reviewing this repository?** Start with [docs/review_guide.md](docs/review_guide.md). It covers:

- reading order;
- verification commands (offline, no API key);
- a requirement → code → test map;
- deviations from the original spec;
- the areas that most deserve scrutiny.

Requirements are not duplicated here. If this file and the spec ever disagree, the spec wins.
